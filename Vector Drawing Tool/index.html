Notes:
  • Drag with a mouse, finger, or Apple Pencil to draw a new calligraphy object.
  • Use a two-finger pinch on touch devices to zoom the canvas.
  • Each object keeps its own spine, nib settings, smoothing, and export mode.
  • Use the layers panel to select which object you are editing.
  • Export Spine SVG is the plotter-friendly centerline output.
