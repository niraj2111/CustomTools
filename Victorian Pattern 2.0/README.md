# Victorian Flourish 2.0

The Victorian tool rebuilt directly from the supplied Sprout Brush prototype. It is a standalone browser application with the same interaction model and control surface:

- drag-to-grow stems with recursive scrolls, leaves, bands, collars, and pocket ornament
- medallion, candelabrum, rinceau, rosette, tree-of-life, corner, and free-scroll presets
- mirror, four-way, and radial symmetry
- rectangle, rounded, oval, circle, arch, and band frames
- draggable oval and rectangular voids with collision-aware growth
- undo, clear, regrow, and copyable plotter-ready SVG
- responsive floating panel, light/dark appearance, and mobile support

Open [index.html](./index.html) directly or serve this folder with any static file server.
