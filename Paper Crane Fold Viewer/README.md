# Paper Crane Fold Viewer

Interactive origami fold viewer with a paintable UV canvas and a textured 3D crane preview.

## Features

- step-by-step fold map (6 steps) with keyboard and button navigation
- direct drawing on the 2D paper square
- live UV texturing applied to a rotating WEBGL crane
- brush color, brush size, eraser, and clear controls

## Usage

Open [index.html](./index.html) in a local static server, then:

1. Move through steps using **← / →** or **prev / next** buttons.
2. Draw on the square in any step.
3. Drag the 3D panel (bottom-right) to rotate the crane.
4. Toggle wing overlays or erase/clear your drawing as needed.
