# CalligraphyComposer

Standalone paper-scale text composition tool for calligraphy layouts.

Current MVP:

- Real paper sizes through `shared/paper.js`
- Interactive wrapped text boxes
- Box move and resize handles on canvas
- Font size, line height, tracking, padding, and nib dimensions in millimetres
- Round and broad nib preview styles
- SVG export

Planned next:

- Multi-style spans inside one text box
- Better nib-accurate vector glyph expansion
- Shared text-layer module extraction for reuse in other tools
