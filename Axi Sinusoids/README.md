# Axi Sinusoids

Plotter-friendly square-wave rows with frequency modulation controls and SVG export.

## Features

- p5.js live preview with Tweakpane controls
- canvas dimensions in millimeters
- adjustable row/column density, amplitude, and frequency mapping
- manual SVG export that matches the preview geometry

## Usage

Open [index.html](./index.html) in a local static server and tweak the controls, then use `Export SVG`.
